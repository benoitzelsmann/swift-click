# Visual assets

- `app.ico` is the Swift Click application icon.
- `click-right.png` is a controller illustration created for Swift Click from a supplied reference.
- `mywhoosh.png` originates from `assets/mywhoosh.png` in OpenBikeControl/bikecontrol and identifies the connected application.
- `help/mywhoosh-*.png` are supplied MyWhoosh interface screenshots used by the connection guides.
- Page badges are painted as vectors by the interface. Other application icons are read from the installed Windows apps at runtime and are not redistributed here.

Zwift and MyWhoosh names, logos and interface elements belong to their respective owners. Publication in this repository does not grant rights over those third-party elements. Swift Click is an independent project.
